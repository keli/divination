# 易问

基于高岛流略筮法的在线易经算卦工具，简单方便且准确率高。

## 特点

- 🎯 **简化起卦**：采用高岛流略筮法，仅需输入三个数字即可起卦
- 🔮 **单爻发动**：有且仅有一爻发动，符合传统占卜原理
- 🤖 **AI 解卦**：集成多个主流 AI 工具（DeepSeek、ChatGPT、Claude、Kimi、通义千问）辅助解读卦象
- 🎲 **随机模式**：支持随机生成数字，让天意引导
- 📱 **响应式设计**：基于 Streamlit 构建，界面简洁美观

## 演示页面

## 安装使用

### 环境要求
- Python 3.7+

### 安装依赖
```bash
pip install streamlit
```

### 运行应用
```bash
streamlit run app.py
```

应用将在浏览器中自动打开，默认地址为 `http://localhost:8501`

## Docker 部署

```bash
# 构建镜像
docker build -t divination .

# 运行容器
docker run -p 8501:8501 divination
```

## 使用说明

1. **集中精力**思考需要算卦的事由
2. **输入事由**：简要描述你要占卜的问题（一事一卦，心诚则灵）
3. **输入三个数**：可手动输入或点击"🎲 随机生成"
4. **点击算卦**：系统将显示本卦、变卦及详细卦辞
5. **AI 解卦**：可选择任一 AI 工具获取更详细的解读

## 起卦原理

本程序采用高岛流略筮法：
- 第一个数确定上卦（除以 8 取余）
- 第二个数确定下卦（除以 8 取余）
- 第三个数确定动爻位置（除以 6 取余）
- 根据动爻变化得到变卦
